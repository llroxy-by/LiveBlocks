# fixtures/

测试夹具目录。

- 骨架阶段（LB-001）只有 `skeleton.json`：一条占位夹具，用于验证「fixtures 目录被测试真实读取」这条链路，不含任何业务数据。
- 从 LB-002（合成卡片图像生成器）起，本目录存放业务夹具：合成卡片图像 + 真值 JSON（卡片 id、角点、位姿）、以及后续的 golden 快照。

约定：

1. 夹具必须是**确定性**的：生成脚本固定随机种子，重跑字节一致。
2. 每个夹具都要能追溯到生成它的脚本与提交（在 PR/Issue 中说明）。
3. 单个体积较大的二进制夹具（如整帧图像）入库前先确认仓库体积可接受。
